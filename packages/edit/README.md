# @edit-issebya/edit

The edit model shared by the studio and the worker: the word-anchored edit format, the issebya
style preset, the HarfBuzz builder that turns a version into a HyperFrames page, its layout checks
and the version operations. TypeScript source with no build step and no platform API.

How to run the repository is in the root [README](../../README.md); what the package does is in
the feature docs listed in [docs/conditional-docs.md](../../docs/conditional-docs.md).
