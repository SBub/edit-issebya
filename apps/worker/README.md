# @edit-issebya/worker

The reel studio's job worker, which runs on the owner's machine (never on Vercel).

How to run it is in the root [README](../../README.md); what it does is in the feature docs
listed in [docs/conditional-docs.md](../../docs/conditional-docs.md).

To run the worker in a Docker container (everything it needs in the image, nothing native on the
Mac), see [app_docs/worker-container.md](../../app_docs/worker-container.md).
